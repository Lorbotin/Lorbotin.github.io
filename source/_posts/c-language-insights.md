初步学习完 C 语言（B 站课程），对它有了大致了解。但仍然存在**没有思路**的问题——这篇笔记记录的就是我拆解「没有思路」这件事的过程。

## 一、算法是什么？

算法就是在处理代码时的**数学思考能力**，它有一定的模板和技巧。初学阶段常接触的基础算法（C 入门）：

1. **枚举（暴力）**：挨个试，比如找 100 以内的完数、判断素数
2. **累加 / 累乘**：求和、阶乘
3. **交换两个变量**（临时变量法）
4. **查找**：顺序查找（一个个比对）
5. **排序**：冒泡排序（入门必学）
6. **简单模拟**：约瑟夫环、水仙花数这类题，按规则一步步模拟过程

目前阶段的策略：在模仿代码时**逐步理解代码含义，记忆一些代码技巧**。

## 二、各题型的领悟碎片


**约瑟夫环**

1. 运用 0 和 1
2. 在有编号的题目中，数组下标可以运用
3. 学会如何控制循环返回

**完数查找**

1. 学会找因子
2. 运用 for 循环
3. 对于这种题从一个角度找即可（即从小到大找因子）

**顺序查找**

1. 函数的调用
2. 理解 return 的意义（将值还给 int 型函数）
3. 理解函数调用的数据对应


### scanf 的读取要求

读取顺序由 `&` 的顺序决定；格式串里**有无空格不重要**——读取过程中会自动跳过空白符和回车。

变量定义不要写在循环内，不然每次循环都会重置。养成习惯：若要添加变量，写在开头。

### #define 宏定义

```c
#define N 5   /* 数据预处理：把 N 换成 5，注意末尾不加分号 */
```

宏的含义就是把 `N` 原样替换成 5。如果 `N` 是某个数组的长度，它就是控制遍历数组时的循环次数——比如之前我控制循环是要求输入到 `i = -1` 为止。

宏定义是「文本替换」，不是语句，**末尾不要加分号**，多个替换项之间也不用逗号。

### for 循环与阶乘

求阶乘时，每下一个数的阶乘就是上一个数的阶乘乘上它本身——所以在循环中就能体现出来：

```c
long long fact = 1;
for (int i = 1; i <= n; i++) {
    fact *= i;   /* i! = (i-1)! * i */
}
```

## 三、ASCII 码表

核心就是 `char`（`%c`）和 `int`（`%d`，十进制 decimal）的转换：扫描进来的是字符 `%c`，对照 ASCII 码表就得到它的 `%d` 形式。

`char` 在计算机中的存储方式就是 ASCII 编码。所以如果要在数组中用 char 当下标，要先转化再运用，例如 `a[i - '0']` 把字符 `'3'` 变成整数 `3`。

## 四、理解数组

1. 数组下标 `a[i]` 中的 `i`
2. 数组的数据即 `a[i]` 这个整体的值

运用时记住：**有现成的排好序的序列，即数组下标**，可以运用在标号的时候。

数组下标本质是个整数。`char` 字符参与下标运算时会按 ASCII 值转成整数，所以字符要减 `'0'` 转化后再用。

## 五、最大公约数（辗转相除法）

```c
while (b != 0) {
    r = a % b;
    a = b;
    b = r;
}
/* 循环结束后 a 即为最大公约数 */
```

原理：如果 d 能同时整除 a 和 b（d 是 a、b 的公约数），那么 d 一定可以整除 a−b，也一定可以整除 a 除以 b 的余数。

## 六、合并数组与 OJ 规范

- **合并数组（双指针归并）**：两个有序数组各一个指针，每次取较小的放入结果数组。
- **OJ 审核事宜**：输出数据的标准化，**不要多也不要少**（空格）——即要求代码编写时对输出格式做严格的区分。

## 七、唱歌比赛题（去最高最低分求平均）


- 处理题目时**不要想得太复杂**：「去除」即在最后计算时减去即可。
- 对于循环：要读取 n 个同学的数据，每个同学有 m 个数据，则在循环过程中把一些变量**在循环开始时初始化**。
- 关于找最大最小值：最开始的初始化，将每组数据的**第一个数作为初始值**，在后面读取的过程中不断用新值比较，从而获取最大最小值。


## 八、二维数组与指针

- `mat` 不是普通的 `int *`，它表示**指向第 0 行的地址**，相当于 `&mat[0]`。
- 指针箭头运算符 `->`：`t->hour` 等价于 `(*t).hour`。
- `arr + i` 表示指针往后跳 i 行；`*(arr + i)` 等价于 `arr[i]`，也等价于 `&arr[i][0]`。
- 二维元素的标准指针写法：`*(*(arr + i) + j)` 等价于 `arr[i][j]`。

### 闰年判断

- 条件 1：能被 4 整除但不能被 100 整除——例如整年 1900 不是闰年
- 条件 2：能被 400 整除（整百年看这条）

```c
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
    printf("闰年");
```

### 结构体

```c
typedef struct {
    int hour;
    int minute;
} Time;   /* 结构体的名字 */

Time t;        /* 后面的声明可以有 Time t，用 . 加成员名使用 */
Time *p = &t;  /* 区分：这是指针，用 -> 访问成员 */
```

## 九、实参和形参

- **形参**：函数定义括号里的变量，只是占位符，函数调用前不分配内存。
- **实参**：调用函数时传进去的真实数据（常量、变量、表达式）。

## 十、递归：函数自己调用自己

以二进制输出为例：

```c
void fun3(int x) {
    if (x == 0) return;
    else fun3(x / 2);        /* 先递归，printf 排在后面 */
    printf("%d", x % 2);     /* 满足 x==0 时，先前的计算结果倒序输出 */
}
```

`fun3(x/2)` 先执行，`printf` 排在后面——类似**叠盘子**，最后输出从上往下进行，即后进先出（正是栈的思想）。
